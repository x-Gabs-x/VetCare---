# VetCare---
Sistema de Prontuário e Agendamento Veterinário. Aplicação full-stack com frontend em React, backend em Node.js + Express, banco de dados MongoDB, APIs RESTful e GraphQL (Apollo Server) e autenticação via JWT. Centraliza cadastro de tutores, pets, consultas, histórico de vacinação e agendamentos para clínicas veterinárias de pequeno e médio porte.
